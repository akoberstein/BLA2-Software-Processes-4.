# BLA 2 - Software Processes

## Project Overview
This project explains software processes and applies course concepts to GitHub.com and Netflix streaming. Topics include Waterfall, incremental development, integration/configuration, plan-driven and agile development, requirements/specification, design and implementation, validation, evolution, coping with change, prototyping, and real-world software delivery.

## Real-World Applications
1. GitHub.com, developed and maintained by GitHub. Public engineering evidence shows automated CI, pull-request workflows, merge queues, staged deployment, and continuous improvement.
2. Netflix streaming, developed and maintained by Netflix. Public engineering evidence shows personalization, distributed services, simulation/device testing, experimentation, and continuous evolution.
